# VoiceShield v0.1.1

**Release date:** 2026-10-25

## Supported scope

- Local development and demonstration on an Apple Silicon Mac.
- Authorized local microphone capture and WAV/FLAC file analysis.
- Advisory, uncalibrated acoustic anomaly scoring with explicit abstention and
  mixed-evidence reporting.
- Fail-closed prerequisite validation for an official ASVspoof 2019 LA
  evaluation using the separately acquired AASIST-L checkpoint and dataset.

## Changes

- Offline file analysis preserves meaningful raw threshold crossings and
  uncertain windows. A terminal LOW window no longer presents contradictory
  history as uniformly low; HIGH still requires sustained temporal-policy
  evidence.
- The ASVspoof reproduction runner validates official eval cardinality,
  protocol-to-audio coverage, unique IDs, deterministic two-class smoke
  allocation, canonical eval-only EER comparison, provenance, and complete
  report rendering.
- Reproduction documentation now distinguishes raw logits, uncalibrated
  softmax scores, the local diagnostic normalized minDCF, and official min
  t-DCF.

## Validation evidence

- The official eval prerequisite check passed with 71,237 protocol trials:
  7,355 bona fide and 63,882 spoof.
- Coverage validation found 71,933 unique FLAC stems, zero missing protocol
  files, and 696 permitted extras.
- The complete local `make check-all` gate passed.
- Linux CI passed on the exact feature commit in
  [workflow run 40140147781](https://github.com/ABHIGYA0205/voiceDetection/actions/runs/40140147781).
- One 23.7-second ElevenLabs example produced 20 windows with four raw
  threshold crossings and no sustained-high decision. v0.1.1 reports that
  history as MIXED/UNCERTAIN; this verifies evidence preservation, not detector
  accuracy or modern-TTS reliability.
- The unchanged real-checkpoint M3 engineering benchmark remains available in
  the [canonical Markdown report](../../reports/benchmarks/m3_benchmark_report.md)
  and [canonical JSON report](../../reports/benchmarks/m3_benchmark_report.json).

## Explicit limitations

- The full ASVspoof scoring attempt on an 8 GB M3 Mac was interrupted because
  of severe memory pressure. Its incomplete output is invalid and is not
  release evidence.
- No locally reproduced EER, official min t-DCF, calibrated probability,
  modern-generator accuracy, or broad scientific-validity claim is made.
- Thresholds remain unvalidated operating heuristics. VoiceShield does not
  authenticate callers, prove identity or fraud, automatically block calls, or
  intercept cellular calls.
- The AASIST source, checkpoint, and ASVspoof dataset have separate rights. The
  checkpoint and dataset are not redistributed by VoiceShield.
- This is not a production deployment or security certification.
