# VoiceShield v0.1.0

**Release date:** 2026-10-25

## Supported scope

- Local development and demonstration on an Apple Silicon Mac.
- Authorized local microphone capture.
- WAV/FLAC file analysis.
- Advisory acoustic anomaly scoring.
- The official verified AASIST-L checkpoint loaded separately from its pinned
  upstream source.

## Explicit limitations

- ASVspoof local scientific reproduction has not been completed.
- Probabilities are not calibrated; thresholds remain operating heuristics.
- No accuracy claim is made for modern generators, Indic languages, replay,
  codecs, telephony, or noisy channels.
- VoiceShield cannot intercept cellular calls.
- It does not automatically block calls, prove identity, or prove fraud.
- The checkpoint and evaluation datasets have separate rights and are not
  redistributed by this project.
- This is not a production deployment or security certification.
